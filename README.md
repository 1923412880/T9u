# T9u

一个仿 iOS 原生风格的拨号应用，支持 T9 拼音搜索、双卡管理、归属地显示等功能。

## 功能特性

- 📞 **原生拨号盘**：完美复刻 iOS 原生拨号界面，支持深色/浅色模式自适应
- 🔍 **T9 拼音搜索**：支持中文姓名拼音首字母搜索联系人，输入数字即可匹配
- 📍 **号码归属地**：内置离线数据库，自动识别号码归属地及运营商
- 🛡️ **骚扰拦截**：内置骚扰电话标记功能，识别广告、诈骗、推销等
- 📋 **最近通话**：记录拨号历史，支持快速回拨和滑动删除
- ⚙️ **设置项**：支持自定义 SIM 卡名称、拨号音效、触感反馈等

## 安装要求

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+

## 安装方法

1. **克隆仓库**：
   ```bash
   git clone https://github.com/你的用户名/T9u.git
   cd T9u
   ```

2. **打开项目**：
   ```bash
   open T9u.xcodeproj
   ```

3. **配置签名**：
   在 Xcode 中点击项目名 -> `Signing & Capabilities`，选择你的开发团队 (Team)。

4. **编译运行**：
   选择模拟器或连接真机，按下 `Cmd + R` 运行。

## 技术栈

- **UI 框架**：SwiftUI
- **架构**：MVVM
- **数据存储**：UserDefaults, Contacts Framework
- **电话集成**：CallKit, URL Scheme (tel://)
